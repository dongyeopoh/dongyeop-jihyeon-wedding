# 보안 정책

## 보호 대상

| 자산 | 어디에 있나 | 노출되면 |
|---|---|---|
| GitHub 개인 접근 토큰 | 있어서는 안 됨 (2026-10-26 에 남아 있던 토큰을 폐기하고 주소에서 제거함) | 저장소 전체에 쓰기 가능. 사이트 변조, 방명록 이슈 삭제 가능 |
| 네이버 지도 클라이언트 ID | `.env`(로컬 전용) → 빌드 시 번들에 포함 | 공개가 전제인 키. 다른 도메인에서 쓰려 해도 네이버 콘솔에 등록된 URL 이 아니면 거부됨 |
| 양가 계좌번호 | 소스와 새 빌드에는 없음(2026-10-26 삭제). 재배포 전까지 운영 번들에, 그 뒤에도 `gh-pages` 옛 빌드 커밋에 잔존 | 금융 정보 노출 |
| 양가 부모님 성함, 신랑·신부 이름 | `src/data.json` | 청첩장이므로 공개가 의도된 정보 |
| 방명록 글 | GitHub 이슈 댓글 | 공개 저장소이므로 누구나 읽을 수 있음. 작성자도 이를 전제로 씀 |

## 인증과 권한

사이트 자체에는 로그인이 없다. 권한은 세 주체로 나뉜다.

| 주체 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|
| 익명 방문자 | 모든 섹션 열람, 지도 조작, 외부 링크 열기, 방명록 읽기 | 방명록 쓰기 |
| GitHub 로그인한 방문자 | 위에 더해 방명록 쓰기(자기 GitHub 계정 이름으로 남음), 자기 글 수정·삭제(GitHub 에서) | 남의 글 삭제, 사이트 수정 |
| 저장소 소유자(dongyeopoh) | 사이트 배포, 방명록 이슈·댓글 삭제와 잠금, 지도 키 발급·폐기 | 방문자 식별(IP 등은 어디에도 기록되지 않음) |

방명록 로그인 실패 경로: GitHub 로그인 창을 닫거나 utterances 앱 인가를 거부하면 글쓰기 창이 비활성인 채로 남고, 기존 글 읽기는 계속 가능하다. 저장소가 비공개로 바뀌거나 utterances 앱이 저장소에서 제거되면 방명록 영역 전체가 빈 칸이 된다.

## 자격 증명 관리

- **GitHub 접근**: git 푸시는 SSH 키 또는 운영체제 자격 증명 관리자로 한다. 토큰을 저장소 주소(`https://user:token@github.com/...`) 안에 넣어 두는 방식은 금지한다. `package.json`, `.git/config`, 셸 기록 어디에도 `ghp_` 로 시작하는 문자열이 남아 있으면 안 된다. 푸시 인증은 `gh auth login` 으로 로그인한 `dongyeopoh` 계정의 자격 증명을 쓴다.
- **네이버 지도 클라이언트 ID**: 네이버 클라우드 플랫폼 콘솔의 Maps 애플리케이션에서 발급한다. 발급 시 "Web 서비스 URL" 에 `https://dongyeopoh.github.io` 와 로컬 개발 주소(`http://localhost:5173`)를 등록해야 두 환경 모두에서 지도가 뜬다. 교체 절차: 콘솔에서 새 ID 발급 → `.env` 값 교체 → 다시 빌드 → 배포. 옛 ID 는 콘솔에서 삭제한다. 만료 기한은 없고, 콘솔에서 삭제하는 순간 무효가 된다.
- `.env` 는 git 에 절대 올리지 않는다(`.gitignore` 에 등록되어 있음). 새 컴퓨터에서는 콘솔에서 ID 를 다시 확인해 `.env` 를 손으로 만든다.

## 개인정보 정책

- 공개 번들과 저장소 어디에도 계좌번호가 있어서는 안 된다. "화면에서 안 보이면 된다" 는 기준이 아니다. 소스에서는 지웠고, 계좌번호 없는 번들을 배포하는 것까지가 완료 조건이다. 계좌 안내가 다시 필요해지더라도 `data.json` 에 계좌번호를 되살리지 않는다.
- 전화번호는 어디에도 넣지 않는다. 연락처 섹션은 원래부터 없다.
- 부모님 성함과 신랑·신부 이름은 유지한다. 예식 장소·일시도 공개 정보다.
- 방문자에 대해 수집하는 정보는 없다. 분석 도구, 쿠키, 로컬 저장소 사용이 없으며 새로 추가하지 않는다.

## 기록(감사) 대상

- 사이트 변경 이력: main 브랜치와 gh-pages 브랜치의 git 커밋이 유일한 기록이다. 누가 언제 무엇을 배포했는지는 커밋으로만 추적된다.
- 방명록 작성·수정·삭제: GitHub 이슈의 댓글 이력이 기록이다. 사이트는 별도 기록을 남기지 않는다.
- 지도 키 사용량: 네이버 클라우드 콘솔에서만 확인할 수 있다.
