# 외부에 약속한 인터페이스

이 프로젝트가 제공하는 API 는 없다. 외부가 기대는 약속은 아래 세 가지뿐이며, 이것이 바뀌면 링크를 받은 사람과 연결된 서비스가 깨진다.

## 공개 주소

- `https://dongyeopoh.github.io/dongyeop-jihyeon-wedding/` 가 유일한 주소다. 이미 하객들에게 전달된 링크이므로 저장소 이름, 사용자 이름, 경로를 바꾸면 그 링크들이 전부 404 가 된다. 주소를 바꿔야 한다면 옛 주소에서 새 주소로 넘기는 페이지를 남겨야 한다.
- 질의 문자열이나 해시(`#`)는 해석하지 않는다. 어떤 뒤꼬리가 붙어도 같은 페이지가 뜬다.

## 링크 공유 미리보기 (Open Graph)

메신저와 SNS 크롤러가 읽는 값이다. `index.html` 의 `<head>` 에서만 제공되며 JS 로 바뀌지 않는다.

| 항목 | 값 |
|---|---|
| `og:title` | 동엽이와 지현, 결혼합니다 |
| `og:description` | 2024년 11월 2일 (토) 12:00 무주 태권도원 명인관 |
| `og:site_name` | 동엽이와 지현이의 모바일 청첩장 |
| `og:url` | 위 공개 주소 |
| `og:locale` | ko_KR |
| `og:image` | 1500×1000 사진. 현재는 만료된 외부 주소라 사진이 나오지 않으며, 사이트 안 파일로 교체 예정 |

## 방명록 저장 형식 (GitHub 이슈)

- 저장소 `dongyeopoh/dongyeop-jihyeon-wedding` 에 제목이 `/dongyeop-jihyeon-wedding/` 인 이슈 하나가 방명록이다. 글 하나가 댓글 하나이며, 작성자는 글쓴이의 GitHub 계정이다.
- 사이트는 이 이슈를 읽기만 하고, 쓰기는 utterances 가 글쓴이의 GitHub 인가로 수행한다. 저장소 소유자는 이 이슈를 GitHub 에서 직접 관리(댓글 삭제, 잠금)할 수 있고, 잠그면 사이트에서 새 글이 막힌다.
