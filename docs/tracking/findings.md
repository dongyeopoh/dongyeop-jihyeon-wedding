# 미해결 문제

## 공개 번들에 양가 계좌번호가 남아 있다

- 조건과 증상: 운영 중인 사이트의 `assets/index-C0xOuYl9.js` 를 열면 옛 `src/data.json` 전체가 들어 있어 계좌번호 네 개와 카카오페이 송금 링크가 평문으로 보인다. 소스와 새 빌드에서는 사라졌지만, 재배포 전까지 운영 번들에, 그 뒤에도 `gh-pages` 의 옛 빌드 커밋에 남는다.
- 영향: 당사자와 부모님의 금융 정보 노출.
- 지금 못 고치는 이유: 운영 번들은 배포 전 화면 확인을 기다리는 중이다. `gh-pages` 옛 기록은 브랜치 이력을 다시 써야 해서 사용자 결정이 필요하다.
- 접근: 미리보기 확인 → `dist/` 커밋 → subtree push. 배포 후 `curl -s <번들 주소> | grep -c 3333-` 이 0 이어야 한다. 옛 기록은 `gh-pages` 를 현재 `dist/` 하나의 커밋으로 새로 만들어 강제 푸시하면 지워진다(방명록 이슈와는 무관하다).

## 링크 공유 미리보기 사진이 깨져 있다

- 조건과 증상: 메신저에 링크를 붙이면 사진 없이 제목·설명만 나온다. `og:image` 의 노션 주소가 2024-10-09 만료되어 403 을 반환한다.
- 영향: 이미 공유된 링크의 미리보기가 모두 사진 없이 보인다.
- 지금 못 고치는 이유: 미리보기로 쓸 사진 파일을 사용자가 골라야 하고, 재배포가 필요하다.
- 접근: 사진을 `public/` 에 넣고 절대 주소로 지정(가로 1500 × 세로 1000 권장). 수정 후 메신저 캐시 때문에 주소 뒤에 꼬리표를 붙여 확인.
