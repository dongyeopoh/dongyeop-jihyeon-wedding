# 미해결 문제

## 네트워크 오류로 지도 스크립트가 한 번 실패하면 재시도되지 않는다

- 조건과 증상: 지도 스크립트 요청이 네트워크 오류로 실패한 뒤 같은 페이지에서 Map 컴포넌트가 다시 마운트되면, 실패한 `<script>` 태그가 문서에 남아 있어 다시 요청하지 않고 곧바로 안내 상자가 뜬다.
- 영향: 현재 페이지는 단일 화면이라 Map 이 다시 마운트되는 경로가 없어 실제로는 발생하지 않는다. 새로고침하면 정상 재시도된다.
- 지금 못 고치는 이유: 발생 경로가 없는 상태에서 재시도 로직을 넣는 것은 보존 모드의 범위를 넘는다.
- 접근: 필요해지면 실패한 태그를 `document.head` 에서 제거한 뒤 다시 삽입하는 분기를 `loadNaverMaps` 에 추가한다.
