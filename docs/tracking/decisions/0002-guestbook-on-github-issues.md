# 0002. 방명록을 GitHub 이슈(utterances)로 운영

## 배경

하객이 축하 글을 남길 공간이 필요했지만 이 사이트에는 서버가 없다. 글을 저장할 곳과 스팸·악성 글을 막을 최소한의 장치가 필요했다.

## 결정

utterances 스크립트를 삽입해 저장소 `dongyeopoh/dongyeop-jihyeon-wedding` 의 이슈(제목 = 페이지 경로)에 댓글로 저장한다. 글을 쓰려면 GitHub 로그인이 필요하다. 2026-10-20, 결혼식이 끝난 뒤에도 방명록을 그대로 유지하기로 확정했다.

## 검토한 대안

- **외부 댓글 서비스(Disqus 류)**: 로그인 장벽은 낮지만 광고·추적 스크립트가 붙고 글의 소유권이 외부에 남는다. 기각.
- **구글 폼 또는 시트 연동**: 로그인 없이 쓸 수 있지만 화면에 글이 바로 보이지 않고, 폼 주소를 공개하면 스팸을 막을 수 없다. 기각.
- **자체 백엔드(서버리스 함수 + DB)**: 유지·비용·보안이 청첩장 규모에 과하다. 기각.

## 결과

- 하객 중 GitHub 계정이 없는 사람은 글을 남길 수 없다. 이를 알고도 받아들인 제약이다.
- 저장소는 반드시 Public 이어야 하고 utterances GitHub 앱이 설치되어 있어야 한다. 저장소를 비공개로 바꾸는 순간 방명록이 사라진다.
- 페이지 경로(`/dongyeop-jihyeon-wedding/`)가 이슈 제목이므로, 저장소 이름이나 base 경로를 바꾸면 기존 방명록과의 연결이 끊긴다.
- 글 관리(삭제, 잠금)는 GitHub 에서만 가능하며 사이트에는 관리 UI 가 없다.
